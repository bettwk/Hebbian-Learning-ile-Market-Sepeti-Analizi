# Hebbian-Learning-ile-Market-Sepeti-Analizi
Derste gördüğümüz "Hebbian Öğrenmesi" kuralını aldım ve markette aynı sepete giren ürünlerin birbirine bağlanması mantığına uyarladım. Hazır makine öğrenmesi kütüphaneleri kullanmadan, işin matematiğini koda dökmeye çalıştım.

Kaggle'dan yaklaşık 500 bin satırlık bir market verisi kullandım. Ama dosya çok büyük olduğu için ve Kaggle'ın lisans muhabbetleriyle uğraşmamak için veriyi buraya yüklemedim (sadece kodlar var).

Eğer kodu kendi bilgisayarınızda test etmek isterseniz:
-Link üzerinden veriyi indirebilirsiniz: https://www.kaggle.com/datasets/aslanahmedov/market-basket-analysis
-Bilgisayarınızda openpyxl, pandas ve numpy kurulu olduğundan emin olun.
